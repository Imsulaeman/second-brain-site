# Unsupervised Learning

Unsupervised learning is a machine-learning approach in which a system looks for patterns, clusters, or structure in data without being given labeled answers in advance.

It is useful when the goal is exploration rather than direct prediction: grouping similar cases, finding recurring structures, or noticing relationships that were not manually specified beforehand.
