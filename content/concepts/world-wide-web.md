# World Wide Web

The World Wide Web is a distributed hypertext system that runs on top of the internet. It is made of interlinked resources identified by URLs, retrieved through browsers and servers, and held together by standards such as HTML and HTTP.

The most important distinction is negative: the web is not the internet itself. The internet is the underlying network infrastructure that moves data. The web is one application layer built on top of that infrastructure, alongside many other services and protocols.

What makes the web historically distinctive is the power of hyperlinks. A page is not only a document. It is a connected node that can point outward to other nodes, turning isolated files into a navigable information structure.
