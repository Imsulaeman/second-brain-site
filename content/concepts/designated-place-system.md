# Designated Place System

Assign one fixed location for each easily-lost essential — keys on a hook by the door, passport in a particular drawer, reading glasses on a particular table — and be scrupulous about returning items there.

[[entities/Daniel-Levitin|Daniel Levitin]] recommends this as a [[concepts/premortem|pre-mortem]] system: prevent the small failures (lost keys, forgotten passport) that cascade into catastrophes under stress.

## Why It Works: Spatial Memory

The [[concepts/hippocampus|hippocampus]] evolved to track locations of important resources — wells, fruit stands, tribal territories. London cab drivers grow enlarged hippocampi from navigation training. Squirrels find buried nuts via hippocampus even when olfactory sense is disabled.

The mechanism is exquisitely good for **things that don't move**. It fails for objects that migrate — car keys, reading glasses, passports — which is exactly why those items disappear.

Fixing location removes the search problem. If you're scrupulous, the item is always where you look.

## Relation to Environment Design

This is a narrow application of [[concepts/environment-design-for-habits|environment design]]: structure the environment so stressed recall isn't required. Unlike habit stacking (cue → behavior), designated places solve object retrieval — a different failure mode.
