# Supervised Learning

Supervised learning is a machine-learning approach in which a model learns from examples that already include the desired answer or label.

Its basic pattern is simple: show the system many cases, compare its predictions to known outcomes, and adjust its internal parameters so future predictions improve. It is the standard mode for classification and prediction tasks where good labeled data exists.
