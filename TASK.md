### [CODEX] Fix Mermaid node label clipping

**Status:** `[x]` done  
**Planned by:** Claude 2026-05-17  
**File:** `components/MermaidDiagram.tsx`

**Why previous attempts failed:**  
- `overflow: visible` on SVG → parent `overflow-auto` clips regardless  
- Removing `height: auto` → correct but didn’t fix underlying cause  
- `htmlLabels: true` → fixes clipPath but `<foreignObject>` height is computed differently by Mermaid’s layout engine  
- CSS cannot solve this: `overflow-x: auto` forces `overflow-y: auto` on the same element — no CSS-only way to scroll horizontally and grow freely vertically

**Root cause (final):**  
Mermaid’s layout engine underestimates the SVG `height` attribute when rendering `<foreignObject>` HTML labels. The container’s `overflow-auto` then clips the content at that underestimated height.

**Fix — read viewBox, write corrected height with 48px buffer:**  
Replace the SVG post-processing block (lines after `ref.current.innerHTML = svg`) with:

```ts
const svgEl = ref.current.querySelector(‘svg’)
if (svgEl) {
  svgEl.removeAttribute(‘width’)
  svgEl.style.overflow = ‘visible’
  svgEl.style.minWidth = ‘520px’
  svgEl.style.display = ‘block’

  const viewBox = svgEl.getAttribute(‘viewBox’)
  if (viewBox) {
    const parts = viewBox.trim().split(/\s+/)
    const h = parseFloat(parts[3])
    if (h > 0) svgEl.setAttribute(‘height’, String(h + 48))
  }
}
```

Everything else stays as-is: `flowchart: { htmlLabels: true }`, expand button, fullscreen overlay, all theme variables.

**Verify:** Open `/note/beginner-trader-investor-learning-path`. All three flowcharts fully visible — especially the diamond node `Is this based on value over time?` must show completely. Expand button still works.

useEffect(() => {
