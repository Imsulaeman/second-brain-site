# PRODUCT.md

## Product
Ilham's Second Brain: a personal knowledge website themed as a Memory Palace.
A public-facing digital garden and personal navigation tool built on an Obsidian markdown vault.

## Register
brand: design IS the product. This is a portfolio and knowledge showcase, not an app UI.

## Users
- **Primary:** Ilham: navigates his own notes, browses concepts, finds connections
- **Secondary:** Public visitors: discover his thinking on learning, trading, AI, and decision-making

## Tone
Intellectual, architectural, precise. Curious but not academic. Confident without being loud.
The site should feel like walking into a well-organized private library, not a startup landing page.

## Strategic Principles
- Content is the star; design serves the content
- Every note is a destination, not just a list item
- Navigation should feel spatial (rooms) not hierarchical (breadcrumbs only)
- Speed matters: this is used daily as a personal reference tool

## Anti-References
- Generic Notion-style markdown blogs (flat, no identity)
- Typical developer portfolio sites (too technical, not editorial)
- SaaS landing pages (wrong register, wrong tone)
- Obsidian Publish default theme (too raw)

## Aesthetic Reference
Blue Prince (the game): deep navy, candlelit gold, architectural. Inspired, not copied.
Clean and modern layout. No mystery mechanics, no hidden UI. Just the color mood.
